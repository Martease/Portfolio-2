# Bycra Client Portal Build Plan (MVP -> V2.0)

## MVP Milestones

1. Platform foundations
- App Router portal shell and route groups.
- Auth.js credentials and invitation acceptance route.
- Middleware RBAC and protected route policy.
- Base design tokens, dark mode, loading/suspense patterns.

2. Client core workspace
- Dashboard cards and recent activity feed.
- Project timeline stages with status/progress/notes.
- Kanban board with four required columns.
- Documents list with secure downloads.

3. Billing + notifications
- Stripe invoice list and pay-invoice flow.
- Payment history and receipt download links.
- Notification center with unread states.

4. File uploads
- R2 presigned upload flow.
- Drag-drop + upload progress + delete.
- Version history per upload category.

5. Admin essentials
- Client creation and invitation send.
- Project creation and task assignment.
- Revenue summary and activity stream.

## V1.5 Enhancements

1. Messaging
- Per-project conversation threads.
- Attachments and unread counters.

2. Meetings
- Kickoff/review/launch meeting tracker.
- Calendar links and notes.

3. Hardening
- Rate-limit tuning, security review.
- Better audit event coverage and observability.

## V2.0

1. Website care suite
- Health trendline, monthly updates, completed maintenance.
- Support requests with SLA states.
- Remaining support hours ledger.

2. Collaboration upgrades
- Real-time typing indicator.
- Presence on board and timeline updates.

3. Role expansion
- Designer/Developer/Account Manager permissions.
- Team-based assignment and workload snapshots.

## Suggested sprint order

1. Sprint 1: Foundations + auth
2. Sprint 2: Dashboard + timeline
3. Sprint 3: Board + documents
4. Sprint 4: Billing + notifications
5. Sprint 5: Uploads + admin essentials
6. Sprint 6: Messaging + meetings
7. Sprint 7+: Website care + real-time features
